
# Penetration Testing and Ethical Hacking

## Purpose
Learn how to identify, assess and responsibly report security vulnerabilities in systems and applications with proper authorization.

## Topics to Study
- Ethical hacking fundamentals
- Penetration testing methodology
- Reconnaissance and information gathering
- Network scanning
- Vulnerability assessment
- Web application security
- Authentication and access control
- Common web vulnerabilities
- Security testing tools
- Writing penetration testing reports

## Practical Exercises
Hands-on exercises will be conducted only in authorized labs and practice environments.
