
# Cloud Security Engineering

## Purpose
Develop the knowledge and practical skills required to secure cloud infrastructure, services, applications and data.

## Topics to Study
- Cloud computing fundamentals
- Cloud service models (IaaS, PaaS and SaaS)
- Cloud deployment models
- Amazon Web Services (AWS) fundamentals
- Microsoft Azure fundamentals
- Identity and Access Management (IAM)
- Cloud networking
- Cloud storage security
- Encryption and key management
- Cloud monitoring and logging
- Security policies and compliance
- Cloud threat detection and incident response

Cloud security labs, architecture exercises and security configuration projects will be documented here.
