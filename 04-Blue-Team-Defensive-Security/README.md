
# Blue Team - Defensive Security

## Purpose
Learn how to protect computer systems, networks and information against cyber threats.

## Topics to Study
- Cybersecurity fundamentals
- Security principles (CIA Triad)
- Common cyber threats and attacks
- Malware and phishing awareness
- Security monitoring
- Log analysis
- Incident detection and response
- Firewalls and endpoint protection
- Security Information and Event Management (SIEM)
- Vulnerability management

## Practical Exercises
Defensive security exercises, log analysis and incident response simulations will be documented here.
